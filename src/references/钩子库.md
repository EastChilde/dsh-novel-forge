# 钩子库

钩子只解决一件事：让读者点「下一章」。

## 章末钩子（13 式）

| 类型 | 做法 | 例 |
|---|---|---|
| 悬念-信息差 | 主角知道了一半 | 信上只有半句话，落款被烧掉了 |
| 悬念-身份 | 某人是谁被点破一半 | 老周袖口的刺青，和父亲尸体上的一样 |
| 危机-倒计时 | 明确的时间压力 | 三天后，县衙就会封档 |
| 危机-逼近 | 威胁已经到了门外 | 脚步声停在门口 |
| 反转-立场 | 盟友突然站到对面 | 「我一直在等你自己发现。」 |
| 反转-因果 | 之前的事实被重新解释 | 那场火不是意外，是父亲自己点的 |
| 诱惑-代价 | 得到一个必须付代价的机会 | 他可以现在就杀了褚九，但会失去唯一的证人 |
| 决断-不可逆 | 主角做了不能撤回的选择 | 他烧了那封信 |
| 新信息-世界规则 | 规则比想象中更残酷 | 铜钱在月光下开始发烫 |
| 情感-关系变化 | 关系被一句话改写 | 「你父亲欠我一条命。」 |
| 荒诞-反常 | 出现不合常理的事 | 尸体在第二天早上不见了 |
| 目标-升级 | 目标突然变大 | 他原以为只要查一个人 |
| 收束-新问题 | 旧问题解决，新问题更大 | 内鬼找到了，但他背后还有人 |

使用规则：
- 钩子必须从本章长出来，不能硬贴。
- 相邻三章不要用同一类型。
- 钩子落地后，下一章前 300 字要接住它。

## 章首钩子（7 式）

1. **动作切入**：从正在发生的事写起。
2. **对话切入**：一句有信息量的话。
3. **异常切入**：一个不该出现的东西。
4. **时间压力**：只剩多久。
5. **结果前置**：先说结果，再倒回去。
6. **感官切入**：气味、声音、疼痛。
7. **反差切入**：庄重场合里的一个不体面细节。

## 自查

- 读完这一章，读者有没有一个**具体**的问题想问？
- 这个问题是「会不会」还是「为什么」？后者更强。
- 钩子是否兑现了上一章留下的问题？
