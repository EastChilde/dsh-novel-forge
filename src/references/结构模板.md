# 结构模板

## 三层结构

| 层 | 回答的问题 | 粒度 | 产物 |
|---|---|---|---|
| 全书 | 这本书在讲一个人的什么变化 | 1 张纸 | 00-创意.md 的定位 + 全书大纲 |
| 卷 | 这一段他要打赢谁、付什么代价 | 3–5 章（短）/ 20–40 章（网文） | 卷纲-0X.md |
| 章 | 这一章读者爽在哪、为什么翻下一页 | 2000–3000 字 | 细纲-0XX.md |

## 全书骨架（网文四段）

1. **起（1–15%）**：异常降临 / 屈辱开局 → 获得优势 → 第一次打脸 → 立中期目标。
2. **承（15–55%）**：换地图、换对手、升层级。每卷一个明确目标，卷末必须失败一次或付出代价。
3. **转（55–85%）**：旧秩序崩塌，主角的信念被质疑，最信任的人出问题。
4. **合（85–100%）**：理念对决，把前文所有伏笔收束成一次选择。

文学向可换成「三幕 + 价值转折」，但不要在同一本书里混用两套节拍。

## 场景卡三问

写不出场景时，只回答这三句：

1. 这一场里，谁想要什么？（没有欲望 = 没有戏）
2. 谁/什么挡着他？（没有阻力 = 没有张力）
3. 结束时局面和开始时有什么不同？（没有变化 = 可以删）

## 节奏检查

- 连续三章都在铺垫 → 读者会走。
- 连续三章都在打脸 → 读者会麻。
- 一章里超过两个新设定 → 读者记不住。
- 场景换地点超过三次 → 读者晕。
